# Arvello Design QA Checklist

Use this checklist before marking a UI task complete.

## Visual

- [ ] Brand colors match the design tokens
- [ ] Typography uses the established hierarchy
- [ ] Cards use consistent radius/border/shadow
- [ ] Buttons use approved variants
- [ ] Product images use consistent aspect ratios
- [ ] Section spacing is consistent
- [ ] No random colors
- [ ] No random shadows
- [ ] No unnecessary gradients
- [ ] Visual density feels premium and calm

## Layout

- [ ] Container alignment is consistent
- [ ] Grid alignment is consistent
- [ ] No horizontal overflow
- [ ] No clipped content
- [ ] Long product names do not break layout
- [ ] Empty/error/loading states preserve layout

## Responsive

- [ ] 360px
- [ ] 390px
- [ ] 430px
- [ ] 768px
- [ ] 1024px
- [ ] 1280px+

## Interaction

- [ ] Hover states
- [ ] Focus-visible states
- [ ] Active states
- [ ] Disabled states
- [ ] Loading states
- [ ] Touch interactions

## Accessibility

- [ ] Semantic HTML
- [ ] Keyboard navigation
- [ ] Visible focus
- [ ] Accessible names for icon buttons
- [ ] Image alt text
- [ ] Form labels
- [ ] Errors are not color-only
- [ ] Reduced motion considered

## Engineering

- [ ] Existing components reused
- [ ] No unnecessary dependency added
- [ ] No unrelated refactor
- [ ] Types/lint/tests/build checked when available
- [ ] No console errors
