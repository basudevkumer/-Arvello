# Arvello Iconography System

## Purpose

Keep icons visually consistent across the product.

## Library

Use the icon library already installed by the project.

Do not introduce another icon library unless the existing library cannot satisfy a concrete requirement.

## Style

Preferred icon characteristics:
- simple;
- modern;
- minimal;
- consistent stroke weight;
- visually balanced with the typography.

Avoid mixing filled and outlined icon families without a deliberate reason.

## Sizes

Recommended semantic sizes:

| Size | Use |
|---|---|
| 14px | Tiny metadata/icon-text |
| 16px | Inline UI |
| 18px | Standard controls |
| 20px | Header/actions |
| 24px | Primary navigation/action |
| 32px+ | Feature/empty-state illustration |

Use the closest existing project convention when one exists.

## Icon Buttons

Icon-only controls must have:
- accessible name;
- visible focus state;
- adequate touch target;
- consistent hover/active state.

Examples:
- Search
- Cart
- Account
- Menu
- Close
- Wishlist
- Chevron controls

## Color

Use semantic icon colors:
- primary;
- secondary;
- muted;
- brand;
- inverse;
- disabled.

Do not assign arbitrary colors to individual icons.

## Decorative Icons

Decorative icons must not compete with primary content.

## Agent Rule

Never solve a missing icon by drawing an inconsistent custom SVG if an approved project icon already exists.
